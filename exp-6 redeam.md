Practical Examination Write-Up: Experiment 6

AIM To analyze Application Layer Domain Name System (DNS) protocol transactions by performing forward and authoritative name lookups using CLI utility commands (nslookup) and capturing/inspecting DNS query and response packets using Wireshark Packet Analyzer.

THEORY DNS Architecture: A distributed, hierarchical database system operating at the Application Layer that maps human-readable domain names (FQDN) into numerical IP addresses (IPv4/IPv6). Transport Port & Protocol: Typically uses UDP Port 53 for standard queries due to minimal overhead and fast response times; uses TCP Port 53 when response payload exceeds 512 bytes (EDNS0 allows up to 4096 bytes) or during DNS zone transfers. DNS Hierarchy: Root Domain (.) $ ightarrow$ Top-Level Domain (TLD: .com, .org) $ ightarrow$ Authoritative/Second-Level Domain (google.com) $ ightarrow$ Subdomain (mail.google.com). Common Resource Record (RR) Types: A: Maps hostname to 32-bit IPv4 address. AAAA: Maps hostname to 128-bit IPv6 address. NS: Identifies authoritative Name Servers for a domain. CNAME: Canonical Name (alias to another domain name). MX: Mail Exchange server records and priority metrics. PTR: Pointer Record for reverse DNS lookups (IP to domain). DNS Message Header Structure (12 Bytes): Transaction ID (16-bit): Matches query with response. Flags (16-bit): QR bit (0 = Query, 1 = Response), Opcode (0 = Standard), AA (Authoritative Answer), TC (Truncation), RD (Recursion Desired), RA (Recursion Available), RCODE (Response Code: 0 = No Error, 3 = NXDOMAIN). Counter Fields (16-bit each): Number of Questions, Answer RRs, Authority RRs, Additional RRs.

EXPLANATION / PROCEDURE CLI Lookup Execution: Execute nslookup google.com: Queries local default DNS resolver; displays Non-authoritative Answer with resolved IPv4/IPv6 addresses. Execute nslookup -type=ns bing.com: Directly retrieves authoritative name server records (e.g., ns1.msft.net). Wireshark Packet Capture: Launch Wireshark and select active network interface (e.g., Wi-Fi or Ethernet). Set display filter: dns or udp.port == 53. Re-run nslookup example.com in terminal to trigger live packet exchange. Packet Header Inspection: DNS Query Packet: Verify Destination Port = 53, Flags = 0x0100 (Standard query with Recursion Desired = 1), Questions section contains QNAME = example.com, QTYPE = A. DNS Response Packet: Verify Source Port = 53, Transaction ID matches Query ID, Flags = 0x8180 (Response, Recursion Available = 1, No Error), Answer section displays resolved IP, Resource Record Type (A), Class (IN), and Time-To-Live (TTL in seconds).
